FermentTwin

A Streamlit app that models fermentation batches — feature engineering, multi-target prediction, and an operator UI for digital-twin style what-ifs.

Challenge

Batch fermentation is expensive to iterate in the tank. Operators need a way to ask “what if” against historical runs.

Approach

Engineered batch features, trained multi-target models, and wrapped them in a Streamlit interface so a user can inspect predictions without touching a notebook.

Outcome

A working operator UI for fermentation what-ifs, kept as a personal systems experiment.
